Gerador de Fluxos

Monta o script SQL de um fluxo novo. Não conecta ao banco: você revisa e roda o script no SSMS.
1. Catálogo de ações

Rode no banco e cole o resultado (SSMS: selecione a grade, Ctrl+Shift+C para copiar com cabeçalho, ou Ctrl+C):

SELECT ID, Nome, ComponenteFrontEnd, NomeComponente FROM dbo.Acoes ORDER BY Nome;

O catálogo inicial é só um ponto de partida (nomes = descrições de passos). Cole o catálogo do seu banco para ter todas as ações com os IDs corretos.
